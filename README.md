# TrueTick JavaScript packages

TypeScript SDK and CLI for the [TrueTick](https://truetick.gg) Minecraft hosting API —
honest hosting with guaranteed, never-oversold CPU, live TPS/MSPT, and metered
scale-to-zero (or flat) billing.

| Package | Install | Docs |
|---|---|---|
| [`@truetick/sdk`](sdk/) | `npm install @truetick/sdk` | [docs.truetick.gg/libraries/sdk](https://docs.truetick.gg/libraries/sdk) |
| [`@truetick/cli`](cli/) | `npm install -g @truetick/cli` | [docs.truetick.gg/libraries/cli](https://docs.truetick.gg/libraries/cli) |

The MCP server lives in its own repository: [truetick-gg/mcp](https://github.com/truetick-gg/mcp).

Get an API key at [truetick.gg/dashboard/api-keys](https://truetick.gg/dashboard/api-keys) ·
start at [truetick.gg/developers](https://truetick.gg/developers).

## About this repository

Development of TrueTick happens in a private monorepo; this repository mirrors
released versions. Issues and discussions are welcome right here — for code
contributions, please propose the change in an issue first.
